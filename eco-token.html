ECO Impact Token (Universal RWA)

Instead of issuing dozens of different tokens, we issue one universal asset: the ECO Token. It acts as a universal receipt for funding environmental solutions. One token = One unit of verified impact.

Token Economics

  • Network: Solana (SPL Token)
  • Peg: 1 ECO = $10 USD contribution
  • Supply: Dynamic (minted only when funds are received)
  • Utility: Proof of impact, voting rights on which gaps to fix next, access to verified ESG reports.

How It Works (The Flow)

  1. You Send Funds: You send $100 USDT to our Treasury and receive 10 ECO tokens.
  2. You Tag a Project: In the transaction memo, you write the ID of the solution you want to fund (e.g., MEMO: flare-nigeria).
  3. We Execute: Funds are released to the project (e.g., installing flare capture).
  4. Satellite Verification: We check the satellite data (VIIRS). If the flare is gone, the status changes.
  5. Your Token Updates: The ECO tokens in your wallet are now marked as "Verified Impact". They become a permanent, immutable ESG certificate.

Why One Token?

  • Liquidity: Easier to trade, buy, or donate. No need to hunt for a specific project token.
  • Simplicity: One contract, one wallet, one standard. Less friction.
  • Scalability: If a new gap is found tomorrow, we don't need to deploy a new token. We just add a new project ID.
